🏆 Project Overview
This project is a real-time streaming ETL pipeline built entirely using free tools and running 100% in Docker. It ingests 1-minute live stock market data from Yahoo Finance via yfinance, processes it using Redpanda (Kafka API compatible) and Spark Structured Streaming, stores cleaned data in Delta Lake, orchestrates workflows in Airflow, and visualizes insights on Grafana.
Everything is built like a real production pipeline used at fintech companies or trading firms — but free and local.

🎯 Project Goals
* Build a real-time data engineering pipeline with industry tools.
* Ingest near real-time 1-minute OHLCV data for top 10 US stocks.
* Apply streaming ETL, transformations, upserts, checkpoints, and idempotent MERGE.
* Store cleaned data in Bronze, Silver, Gold Delta tables.
* Run scheduled jobs with Airflow (monitoring, backfill, quality checks).
* Create a premium Grafana dashboard with financial KPIs.
* Design the entire project to be resume-ready & interview-ready.

🔥 Key Features (Industry Standard)
1. Near Real-Time Producer
* Runs every minute
* Fetches top 10 US tickers
* Uses yfinance (auto retry + safe parsing)
* Writes last successful timestamp per symbol
* Retries with exponential backoff
* Follows idempotent design
2. Redpanda Streaming Broker
* Kafka-compatible
* Topic partitioning by symbol
* DLQ topic for failed messages
* High-throughput real-time ingest
3. Spark Structured Streaming ETL
Implements Bronze → Silver → Gold architecture:
Bronze Layer
* Stores raw JSON from Redpanda
* Behaves like a data lake landing zone
Silver Layer
* Type casting
* De-duplication (timestamp + symbol)
* Normalized schema
* Timezone handling
* Forward-filling missing values
* Validation
Gold Layer
* Aggregated features
* Trading KPIs
* Time windows
* Market-volatility metrics
* Cleaned & enriched data for dashboarding
4. Delta Lake
* ACID transactions
* MERGE for idempotency
* Fast updates
* Versioning (time travel)
5. Airflow Orchestration
* Runs producer every minute
* Monitors producer health
* Checks if new data arrived
* Runs backfill DAG
* Runs QC DAG (schema validation, completeness checks)
* Monitors DLQ and alerts on bad messages
* Rebuilds gold table daily

⚙️ Failure Handling (Full Strategy)
Producer
* Exponential retry
* State file for last timestamp
* DLQ on final failure
* Logging to Airflow
* Backfill based on timestamp gaps
Redpanda
* Retention window: 48 hours
* Partition by symbol
* DLQ topic
Spark
* Checkpointing
* MERGE for idempotency
* Retry microbatch
* Save failed microbatch to failed_batches
Airflow
* Email / Slack alerts
* Producer heartbeat DAG
* DLQ monitor DAG
* Backfill DAG
